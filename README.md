# Emanuele Giordano — Portfolio

Public portfolio for Emanuele Giordano, an AI Automation & Product Builder based in Lelystad, the Netherlands.

## What this portfolio proves

- NEXUS: a local-first multi-agent operations system with visible health and approval controls.
- Field Ops: an anonymised responsive field-operations product and QA handoff.
- NEXUS Gym: a React/TypeScript fitness product with automated verification and mobile targets.
- Dioniso Caffè: a public multilingual hospitality ordering codebase.

The case studies distinguish public source, private source and local prototypes. No customer data, credentials or private repository contents are included.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
